# Offline UI fonts

These webfonts are vendored for competition-day use without a browser network request.
They were downloaded from the Google Fonts CSS2 responses for Chakra Petch 400/600 and
Share Tech Mono 400. Both families are distributed under the SIL Open Font License 1.1;
the corresponding license texts are stored beside the font files.
